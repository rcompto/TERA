# TERA INSTALL — Landing Pages

Três opções de landing page para você escolher a que mais combina com a identidade da empresa.

---

## Como visualizar

1. Abra a pasta `WEB`
2. Clique duas vezes no arquivo `index.html`
3. A página de apresentação abrirá no navegador com os 3 layouts disponíveis
4. Clique em **"Visualizar Layout"** em cada card para ver a versão completa

> Recomendamos usar o navegador **Google Chrome** ou **Microsoft Edge** para melhor visualização.

---

## Os 3 layouts

| Layout | Estilo | Cores |
|--------|--------|-------|
| **Layout 01 — Corporativo** | Sólido, técnico e confiável | Azul escuro + Amarelo |
| **Layout 02 — Dark Tech** | Moderno, tecnológico e arrojado | Preto + Verde neon |
| **Layout 03 — Clean Premium** | Limpo, sofisticado e focado em resultado | Branco + Laranja |

## O que está incluso em cada layout

- CTA final com botões WhatsApp e telefone
